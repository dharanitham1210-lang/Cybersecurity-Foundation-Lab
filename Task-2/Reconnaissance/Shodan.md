# Shodan

## What is Shodan?

Shodan is a search engine that indexes Internet-connected devices instead of websites. It helps security professionals discover publicly accessible systems, services, and devices connected to the Internet.

Unlike Google, which indexes web pages, Shodan indexes devices such as servers, routers, webcams, IoT devices, and industrial control systems.

---

## Why is Shodan Important?

Shodan is widely used during passive reconnaissance to identify exposed systems and services without directly scanning the target.

---

## Information Provided by Shodan

- Public IP Address
- Open Ports
- Running Services
- Operating System
- Server Banners
- Geographic Location
- Organization / ISP
- SSL Certificate Information

## Common Search Examples

### Search by Domain

```text
hostname:example.com
```

### Search by Organization

```text
org:"Google LLC"
```

### Search by Country

```text
country:IN
```

### Search by Port

```text
port:443
```

---

## Advantages

- Passive information gathering
- Identifies exposed devices
- Easy to search
- Useful for security assessments

---

## Limitations

- Requires an Internet connection
- Some advanced features require a paid account
- Results depend on Shodan's latest indexing

---

## Ethical Considerations

Shodan should only be used for:

- Authorized security assessments
- Research
- Learning
- Defensive security

Do not use the information to access systems without permission.

---

## Summary

Shodan is one of the most powerful passive reconnaissance tools. It helps security professionals identify publicly exposed systems and understand an organization's Internet-facing infrastructure.
