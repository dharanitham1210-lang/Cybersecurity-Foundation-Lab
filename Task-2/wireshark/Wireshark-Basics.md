# Wireshark Packet Analysis

## Objective

To understand network packet capturing using Wireshark.

## Tool Used

- Wireshark 4.4.6
- Kali Linux

## Steps Performed

1. Opened Wireshark.
2. Selected the eth0 interface.
3. Started packet capture.
4. Observed live network traffic.
5. Identified protocols such as SSDP and ICMPv6.

## Observation

Successfully captured live packets on the network interface.

## Result

Wireshark was successfully configured and used to monitor network traffic.
