# Penetration Testing Methodology

## Objective
Learn and document the penetration testing workflow in a controlled lab environment.

## Methodology

Reconnaissance
↓
Scanning
↓
Exploitation
↓
Post-Exploitation
↓
Reporting

## 1. Reconnaissance
Information about the target system is collected before testing.

## 2. Scanning
Open ports, running services, and possible attack surfaces are identified.

## 3. Exploitation
A known vulnerability is tested in the authorized lab environment.

## 4. Post-Exploitation
The obtained access is analyzed to understand the impact of the vulnerability.

## 5. Reporting
Findings, evidence, impact, and mitigation steps are documented.

## Key Learning
- Understood the penetration testing lifecycle.
- Learned why reconnaissance and scanning are performed before exploitation.
- Practiced documenting security testing activities systematically.

## Environment
- Kali Linux
- Metasploitable2
- Metasploit Framework
- Controlled lab environment
