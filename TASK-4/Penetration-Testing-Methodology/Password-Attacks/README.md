# Password Attacks

## Objective
Understand password authentication testing techniques in a controlled lab environment.

## Tools
- Hydra
- John the Ripper

## Hydra
Hydra was studied for testing authentication services against controlled lab targets.

## John the Ripper
John the Ripper was studied for analyzing password hashes and evaluating password strength.

## What I Learned
- Understanding password-based authentication attacks
- Understanding brute-force and dictionary-based testing
- Importance of strong passwords
- Importance of account lockout and rate limiting
- Understanding password hashing and cracking risks

## Mitigation
- Use strong and unique passwords
- Implement account lockout/rate limiting
- Use secure password hashing algorithms
- Enable multi-factor authentication
- Monitor repeated authentication failures

## Evidence
Screenshots and demonstration evidence will be added from the controlled lab.

## Key Takeaway
Password security depends on strong authentication controls, secure password storage, and protection against repeated authentication attempts.
